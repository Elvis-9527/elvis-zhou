# 关于职业规划

我帮过 20 多个人的职业规划。其中，那些成功拿到 offer 的人有一个共同点：

**他们不是在"优化简历"，而是在"建立目标公司的信息地图"。**

这个差别很大。

## 普通做法 vs 高效做法

### 普通做法

想跳槽的人通常是这样做的：
1. 拿简历，改一改，发给猎头
2. 或者，看职位描述，针对每个职位调整简历
3. 投出去，等反馈

问题：如果缺少岗位筛选和匹配分析，很容易把精力花在并不合适的机会里。

### 高效做法

那些成功的人做的是：
1. **定位 3-5 家目标公司**（不是漫天撒网）
2. **研究这些公司的招聘模式**（职位描述、晋升路径、用人标准）
3. **为每家公司设计一个"目标简历"**（不是通用简历）
4. **建立关系链：找人内推**
5. **最后才是投简历**

这种准备能提高投递的针对性，但结果还取决于岗位供需、经历匹配和招聘阶段，不能承诺固定的转化率。

## 为什么 AI 在这里特别有用

关键的转变是：**从"优化简历"变成"信息搜集和分析"**。

而这正是 AI 最擅长的。

### 阶段 1：研究目标公司

你选了 3 家公司。要搞清楚这 3 家公司想要什么样的人。

通常做法：手工翻公司网站、看职位描述、问业内朋友。费时费力。

高效做法：给 AI 一个清晰的研究框架，让它从多个来源提取信息。

```
请分析目标公司 [公司名] 的人才需求模式。请输出以下信息：

1. 核心职位线
   - 最常见的招聘职位是哪些？
   - 这些职位在公司内的晋升路径是什么？

2. 用人标准
   - 从职位描述看，最重视的 3 个能力是什么？
   - 学历背景的倾向是什么？（985/211，还是看经验不看学历）

3. 经验背景
   - 新进员工通常来自什么公司？
   - 有没有明显的"背景倾向"？（比如互联网公司偏好来自 BAT）

4. 特殊要求
   - 有没有经常出现的特殊要求？（比如"有钉钉生态经验"）
   - 英文要求的强度如何？

5. 成长机会
   - 职位描述中提到了什么样的成长和机会？
   - 这反映了公司的什么价值观？

来源：
- [公司官网招聘页面的职位清单]
- [LinkedIn 上该公司团队成员的背景]
- [最近的新闻和融资信息]
```

有了这个框架，AI 可以系统地提取信息。输出一个结构化的报告。

### 阶段 2：对比你的背景

现在你有了 3 家公司的需求画像。同时，你也要有一个清晰的"自己的画像"。

包括：
- 核心能力（最拿得出手的 3-5 个）
- 过去的成就（有数字、有业务背景）
- 特殊背景（融资、创业、行业沉淀）
- 可提升的方向（什么能力在目标公司更值钱）

然后，让 AI 做对比：
```
我的背景：
[你的详细背景]

目标公司 A 的需求：
[从上面的研究里提取出来]

请分析：
1. 我的背景和目标公司 A 的需求有多少重合？（具体指出哪些能力、哪些经验）
2. 有没有"错配"？（公司重视但我缺的能力）
3. 如果我要向目标公司靠近，最应该强调哪 3 个方面？
4. 简历里现在没有提到、但应该补充的东西有什么？
```

输出应逐项列出匹配证据、能力缺口和待核实信息，避免用缺乏依据的匹配百分比代替分析。

### 阶段 3：设计"目标简历"

有了对比分析，现在设计一份专门针对这家公司的简历。

不是改原来的简历，而是**重新组织和突出**。

例如：
- 目标公司重视"数据驱动"，你的经历里有做过数据分析，那就把这块放大
- 目标公司的职位要求"管理经验"，如果你确实带过团队，就说明人数、职责和结果；仅参与协作时，应如实写清自己的贡献
- 目标公司在"新产品探索"上有战略，你以前做过新品项目，那就把这个项目详细展开

关键不是"说谎"，而是**有针对性地选择和组织**。

### 阶段 4：找内推人

现在你有了一份有针对性的简历。下一步不是投简历，而是**找到推荐人**。

这也是 AI 能帮忙的地方。

从哪找推荐人？
- LinkedIn 上公司内部的人（可能和你有共同背景）
- 业内认识的人（他们可能认识公司的人）
- 自己的校友网络

告诉 AI：
```
我要进入公司 A。这是我的背景。
请帮我找到 3-5 个可能的内推人：

1. 从 LinkedIn 上，找公司 A 的员工，他们的背景和我有什么交集？
2. 我的共同朋友是谁？怎么请他们帮忙介绍？
3. 什么时候联系这些人最合适？（比如，在他们新入职 1-2 个月时，还是稳定后？）
4. 怎么表述我的诉求，让他们愿意帮我推荐？
```

### 阶段 5：投简历和面试准备

内推能帮助信息触达，但不保证面试或录用；没有内推时，也可以通过正式渠道投递。

但还有最后一步：根据面试的可能问题，准备答案。

AI 可以帮你预演：
```
我要面试公司 A 的职位 [职位名]。
我的背景是：[简历内容]
目标公司的需求是：[需求分析]

请模拟 3 个最可能被问的问题，以及建议的答案：
1. 问题 X（为什么要离职现在的公司）
2. 问题 Y（你的核心竞争力是什么）
3. 问题 Z（你怎么理解公司的产品/战略）

答案应该包括：
- 诚实的事实
- 和职位需求的关联
- 具体的例子或数字
```

## 为什么这个方法有效

### 1. 从被动变主动

普通做法是："投简历，看有没有回复"。你是被选的。

高效做法是："我知道我要去哪，我知道那家公司要什么，我在展示我能提供什么"。你是主动的。

### 2. 减少"时间成本"

提前筛选目标公司，可以减少不匹配的投递和面试。但研究本身也需要时间，应结合实际反馈调整投入，不能仅凭投递数量推算节省比例。

### 3. 提升"品质感"

当 HR 看到一份简历，如果这份简历**清晰地映射了公司的需求**，会觉得"这个人是真的了解我们"。

相比之下，那些通用简历、明显是模板的，会让 HR 觉得"这是漫天撒网"。

前者更容易让对方看清经历与岗位的关联。

### 4. 给双方时间思考

提前准备资料并沟通安排，有助于双方更充分地了解彼此；内推本身不决定面试节奏。

双方都有时间充分了解对方。面试也会更深入、更真实。

## 实战步骤

### 第一周：确定目标公司

列出 3-5 家你真的想去的公司。不是"有机会就行"的公司，而是"我真的想加入"的公司。

为什么要有目标？因为只有有了目标，才能做有针对性的准备。

### 第二周：研究这些公司

用上面的研究框架，针对每家公司输出一份"需求分析"。

应该包括：
- 常见的职位类别
- 用人标准
- 所需的特殊技能或背景

### 第三周：对比和调整

拿自己的背景和 3 家公司的需求对比。

输出：
- 对每家公司的匹配证据、能力缺口和待核实项
- 对每家公司，我应该强调哪些方面
- 对每家公司，我缺什么、能不能快速补齐

### 第四周：准备 3 份简历

针对 3 家公司各准备一份简历。

结构可能一样，但内容的组织顺序、项目的详细程度、某些项目的描述方式，都会不同。

### 第五周：建立关系

从 LinkedIn、学校校友、业内朋友等渠道，找到可能的推荐人。

最好是那些既认识你、也认识目标公司内部人员的。

给推荐人发一份"推荐信息包"，包括：
- 你的简历（针对该公司定制的）
- 你对职位的理解
- 你为什么适合

### 第六周+：面试和谈判

获得内推后，等待面试邀请。

参加面试前，用 AI 做充分的预演。

收到 offer 后，有数据支撑，有底气谈薪。

## 最后的思考

我见过很多人在"优化简历"上花了大量时间。改措辞、调顺序、优化关键词。

但这些都是"微观优化"。真正重要的是"宏观战略"：

**你要去哪家公司，这家公司要什么样的人，你能提供什么，怎么把这三个点连接起来。**

一旦宏观战略清楚了，简历本身就会自然地优化。因为你知道要突出什么、要隐去什么。

AI 的价值，就在于帮你做这个"宏观分析和规划"。

它把一个模糊的"我要跳槽"变成一个清晰的、有目标、有步骤、有数据支撑的职业规划。

**从"我应该怎么改简历"，变成"我应该去哪家公司，怎么进去"。**

这个思维的转变，比任何简历技巧都重要。
